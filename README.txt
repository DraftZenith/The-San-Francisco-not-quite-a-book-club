AUTHOR SPOTLIGHT WEBSITE
========================

Files
-----
- index.html: complete responsive website
- assets/nik-organizer.png: the organizer photo supplied for the website

Preview
-------
Open index.html in a modern browser.

Publish online
--------------
This is a static website and does not require a backend. You can publish the folder using a static hosting service such as Netlify, GitHub Pages, or your web host's file manager. Upload index.html and the assets folder together so the photo path works.

Add the past-event video
------------------------
In index.html, find the section with id="portfolio". Replace the placeholder inside .portfolio-box with your video embed code (for example, an iframe supplied by YouTube or Vimeo). Use the embed URL from the video platform.

Before publishing
-----------------
1. Confirm that all package names, prices, and deliverables are accurate.
2. Add written cancellation/refund terms and any applicable privacy information.
3. Confirm that you have permission to use all photos, graphics, and video.
4. Check that the community-size figure, if you choose to add one, is current and verifiable.
5. Confirm your payment provider, payment link, and secure checkout process. This template intentionally does not embed a payment link.
